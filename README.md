ENCRYPTION/ENCRIPTADO (v1.2.0)

ENGLISH (Google Translate):
This files created on python, make an promt to encrypted promt, Basically, it encrypts the code in 2 chained ways:

1. Converts the text to binary, formats it (looking like Morse code), and replaces periods or dashes with certain characters.

2. Converts the previous text to numbers (associated with known ports such as 443), converts them to binary, formats it (looking like Morse code), and replaces it with letters (lowercase and uppercase) and numbers

SPANISH:
Estos archivos creados en Python, combierten un mensaje a un mensaje cifrado. Básicamente, cifra el código de 2 formas encadenadas:

1. Convierte el texto a binario, lo formatea (pareciendo código Morse) y reemplaza puntos o guiones con ciertos caracteres.

2. Convierte el texto anterior a números (asociados con puertos conocidos como 443), los convierte a binario, lo formatea (pareciendo código Morse) y lo reemplaza con letras (minúsculas y mayúsculas) y números.

DEENCRYPTION/DEENCRIPTADO (v1.1.1)

ENGLISH (Google Translate):
These files, created in Python, take a user-supplied message that is supposed to be level two encrypted and convert it into readable text.

1. Take the text, convert it in formatting (it looks like Morse code), then in binary, this binary to numbers and the numbers to text by using known port names.

2. Convert the previous text to formatting (looking like Morse code), that to binary and from binary to letters

ESPAÑOL:
Estos archivos, creados en Python, toman un mensaje proporcionado por el usuario que se supone que está cifrado de nivel dos y lo convierten en texto legible.

1. Tome el texto, conviértalo en formato (parece código Morse), luego en binario, este binario a números y los números a texto utilizando nombres de puertos conocidos.

2. Convierta el texto anterior a formato (pareciendo código Morse), éste a binario y de binario a letras.
